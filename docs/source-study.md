# Étude concrète de la famille A09

Cette étude suit le ledger courant, dont l’empreinte et les commits de référence sont enregistrés dans `source-evidence.json`. Classification : preuve d’implémentation, conforme à DEC-0012/0013 ; aucune nouvelle décision produit. La famille couvre quatorze entrées principales du catalogue, toutes relues au niveau métadonnées/réglages. Sept implémentations épinglées ont été inspectées au niveau code.

Les restaurations Legacy, Windows 7/8, Windows 10 et Overhauled du catalogue alimentent le choix d’une présentation compacte. Les filtres Chrome PiP et le blocage Edge concernent d’autres mécanismes ; ce prototype ne bloque pas les onglets Edge et ne promet pas d’équivalence avec l’intégration d’onglets du shell. « Aero Flip3D Recreation » constitue une autre variante concurrente, pas un deuxième add-on à publier.

La référence taskbar a été réellement lue : README, manifeste, parsing des presets dans `src/config.cpp`, brosses unies, application directe des propriétés, handlers de pointeur, animations Composition et cycle de vie/restauration dans `src/taskbar_configurator.cpp`. Elle expose 45 définitions, dont six sections et 39 valeurs au snapshot enregistré. Ce prototype réutilise la direction et les contrats de settings ; son rendu WPF, ses dégradés et ses effets sont originaux.

Le [SDK natif courant](../docs/shared-capability-contract.md) a été examiné avec son `process_v2.rs` et le protocole du Desktop MyWallpaper. Les codecs ont été réimplémentés depuis leur contrat v5. Le moteur reste en lecture seule. [Microsoft décrit les miniatures DWM et leurs propriétés](https://learn.microsoft.com/en-us/windows/win32/dwm/thumbnail-ovw) ; une miniature rectangulaire ne fournit pas à elle seule une rotation 3D. Le mode cascade reste nommé en conséquence.

Les empreintes diffèrent entre le checkout du catalogue (CRLF) et les fichiers bruts GitHub (LF). `collect-source-evidence.mjs` vérifie explicitement les deux représentations ; aucune différence de contenu n’a été acceptée silencieusement. Aucun code tiers n’est copié depuis ces mods. À la clôture de cette réalisation, DEC-0160 impose le retrait de Windhawk et place le moteur propre et son SDK interne sous licence exclusivement propriétaire ; aucun de ces composants n’est incorporé dans ce companion original. L’exception MIT du SDK/CLI public de DEC-0098 reste distincte. La licence de cet add-on n’accorde aucun droit sur le moteur interne étudié en lecture.
